
# 🏠 House Price Prediction using Machine Learning

This project demonstrates a machine learning approach to predicting house prices based on various features such as the number of rooms, area, location, and more. It uses common data preprocessing techniques, exploratory data analysis (EDA), and regression models to build a predictive pipeline.

## 📂 Project Structure

- `house_price_prediction.ipynb` – Jupyter Notebook containing all the code for data loading, EDA, preprocessing, model training, and evaluation.
- Dataset – Assumed to be included or loaded within the notebook (e.g., from `kaggle` or a CSV file).
  
## 🔍 Features

- Exploratory Data Analysis (EDA) with visualizations.
- Handling missing values and categorical variables.
- Feature selection and scaling.
- Model training using:
  - Linear Regression
  - Ridge Regression
  - Lasso Regression
  - Random Forest Regressor
- Model evaluation using metrics like R², MAE, and RMSE.
- Cross-validation and hyperparameter tuning.

## ⚙️ Requirements

To run the notebook, install the following Python packages:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/aabelatilaw/House-Price-Prediction-using-Machine-Learning.git
   cd House-Price-Prediction-using-Machine-Learning
   ```

2. Launch Jupyter Notebook:
   ```bash
   jupyter notebook house_price_prediction.ipynb
   ```

3. Run the cells step-by-step to see the results.

## 📈 Model Performance

The notebook compares multiple models and uses metrics like R² Score, RMSE, and cross-validation scores to evaluate which model performs best on the dataset.
